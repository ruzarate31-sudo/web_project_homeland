# De patria a patria

## 📄 Descripción

**De patria a patria** es un proyecto web responsivo desarrollado como parte de los **Sprints 5 y 6** del programa de **Desarrollo Web de TripleTen**.
El proyecto presenta una galería visual basada en un diseño de Figma y tiene como objetivo aplicar buenas prácticas de maquetación, diseño adaptativo y organización del código utilizando HTML y CSS.

En el Sprint 6, el proyecto fue ampliado incorporando nuevas secciones, mejoras visuales y el uso de **CSS Grid Layout** para estructuras más complejas.

---

## ✨ Funcionalidad

- Diseño completamente responsivo para **desktop, tablet y mobile**
- Maquetación fiel al diseño proporcionado en Figma
- Uso de CSS Grid Layout para organizar contenido en cuadrícula
- Uso de Flexbox para alineación de elementos
- Aplicación de la metodología BEM para la estructura del código
- Implementación de degradados y estilos visuales según el brief
- Navegación accesible y estructura semántica en HTML

---

## 🧱 Estructura del proyecto (Sprint 6)

En esta versión del proyecto se agregaron las siguientes secciones:

- **Photo Grid**:
  Galería de imágenes organizada mediante CSS Grid, adaptable a distintos tamaños de pantalla.

- **Places**:
  Sección informativa que presenta distintos lugares del mundo, estructurada con Grid Layout y adaptada para desktop, tablet y mobile.

## 📱 Diseño responsivo

El sitio fue desarrollado siguiendo las resoluciones :

- 1280px (desktop)
- 850px (tablet)
- 550px (mobile)

Se utilizaron **media queries** para ajustar el layout, tipografías y espaciados, garantizando una correcta visualización en resoluciones intermedias y evitando el desplazamiento horizontal.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Grid Layout
- Media Queries
- Metodología BEM
- Normalize.css
- Diseño basado en Figma
